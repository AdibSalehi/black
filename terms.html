3. Accounts and security

Registration collects a username and password. Passwords are stored as salted scrypt hashes, not as plain text. The service also records game statistics, friend relationships, and the time/version of the age and terms confirmations. Use a unique password; do not reuse a password from another service. Session tokens are stored in your browser's local storage and active sessions are held in server memory in this version.

4. Game rooms and chat

Room membership, active hands, and room chat are processed in server memory. Chat is visible to people in the same room. Do not share personal, financial, medical, or confidential information in chat. The current release does not provide a full moderation, reporting, or message-retention system.

5. Data storage and retention

Account records are stored in a local JSON data file on the hosting environment. Active rooms and sessions are stored in memory. Depending on hosting configuration, data may be lost when the service restarts or is redeployed. This release does not yet provide self-service account export or deletion. Before operating this service publicly, the operator must publish a working privacy contact and implement an appropriate data access/deletion process and durable, access-controlled storage.
